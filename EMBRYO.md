# Embryo Config Store

Embryo Config Store is Embryo-Zero's fork of [etcd](https://github.com/etcd-io/etcd) (28623d4, commit 28623d4). It does reliable key-value store for cluster state.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
